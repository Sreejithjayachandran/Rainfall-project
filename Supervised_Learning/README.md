# Linear Regression on Kerala Rainfall Data

This small example demonstrates how to build a **simple linear regression** model using the cleaned rainfall dataset generated by the ETL pipeline.

## What the script does
1. **Loads** the analysis‑ready CSV (`EDA/output/analysis_ready_rainfall.csv`).
2. **Feature engineering** – converts the `date_time` column to a `datetime` object and extracts:
   - `day_of_year` – captures seasonal patterns (monsoon vs. dry season).
   - `year` – allows the model to learn any inter‑annual trend.
   - `latitude` and `longitude` – provide spatial information.
3. **Splits** the data into a training set (80 %) and a test set (20 %).
4. **Fits** a `sklearn.linear_model.LinearRegression` model to predict `rainfall_mm`.
5. **Evaluates** the model on the test set and prints:
   - R² score (coefficient of determination).
   - RMSE (root‑mean‑square error).
   - The learned coefficients for each feature and the intercept.

## Why this is useful
- Shows a complete end‑to‑end workflow from raw data to a predictive model.
- Demonstrates how to quickly add temporal and spatial features for a regression task.
- Provides a baseline model that can be improved (e.g., add lagged rainfall, more sophisticated algorithms, or cross‑validation).
