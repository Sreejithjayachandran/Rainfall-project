# Dataset Description

1. **What is your data source?**
   Kerala manual daily rainfall station data for 2021 (`rainfall_1.csv`). The columns (LGD codes, basin, tributary, acquisition time) match Indian government water-resources data such as India-WRIS. *(https://nwdp.nwic.gov.in/dataset/rainfall-kerala-surface-water-manual-daily/resource/d175f1f6-cccf-4980-97ab-877650d05074)*

2. **Why did you choose it?**
   It is real open-government data, large enough (53,162 rows) to need proper cleaning, and rainfall data is useful for forecasting, flood and agriculture projects.

3. **What information does it contain?**
   Station name, district, tehsil, river/basin/tributary details, latitude and longitude, date-time of the reading, and daily rainfall in mm. It covers 01 Jan 2021 – 31 Dec 2021 for stations across the 14 districts of Kerala.

4. **Is it structured, semi-structured, or unstructured?**
   Structured – fixed rows and columns.

5. **What format is the data?**
   CSV, 20 columns.

6. **How frequently is the data updated?**
   Rainfall is recorded manually every day. This file is a one-time snapshot of the year 2021.
